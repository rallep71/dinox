# DinoX has moved to Forgejo

This GitHub repository is archived and is no longer the active DinoX source.

Use the current DinoX project pages instead:

- Website: https://dinox.im
- Source code: https://git.dinox.im/dinoxim/dinox
- Releases and downloads: https://git.dinox.im/dinoxim/dinox/releases
- Issues: https://git.dinox.im/dinoxim/dinox/issues
- Pull requests: https://git.dinox.im/dinoxim/dinox/pulls
- Contact: contact@dinox.im

DinoX is a free and open-source desktop XMPP messenger for Linux and Windows
with encrypted chat, group rooms, file sharing, voice/video calls, optional Tor
routing, MQTT workflows and Botmother automation.

The old GitHub repository remains available for historical links and stars.
New development, packages, issues and pull requests continue on Forgejo.
